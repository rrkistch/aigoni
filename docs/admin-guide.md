# 日常后台：不改源码管理博客

## 第一次开站

登录后进入“建站引导”。填写站点名称、作者和正式网址，上传头像与Logo，选择需要的页面，再决定如何处理示例内容。已有个人内容不会被引导重置；修改过的示例不会被清理。

写第一篇文章时先保存草稿，生成登录态预览检查排版，再打开“公开”并保存。到“概览”确认“已上线”后再分享链接。保存成功只表示内容落盘，构建可能还在进行。

## 写文章、动态和项目

- “文章／页面”：写博客、维护关于页。链接名称可以修改，已发布旧链接会保留兼容跳转。
- “动态／项目”：在本站编辑Markdown内容。使用Memos时，动态内容改在Memos维护，不混合两套来源。
- 编辑器提供本地摘要、常用Markdown插入、草稿自动保存、封面和附件，以及系列、评论、许可证等展示字段。
- “笔记与收藏／Wiki／AI对话”只在登录后读取。私人附件上传到笔记，不要上传到公开素材库。

## 管理音乐、相册和其他模块

打开“内容模块”，选择音乐、公告、友链、公开书签、打赏展示或公开相册。表单里可以添加、移除、排序和开关；保存后生成网站。

音乐有两种来源：

1. **本地列表**：在“素材”上传音频、封面与LRC歌词，再在音乐歌曲项中选择它们，填写名称与歌手，调整顺序、音量和循环。
2. **外部歌单**：选择Meting模式，填写平台、类型和歌单ID；歌单里的歌曲在原平台维护。

相册首版为公开内容。原版相册展示密码不等于登录权限，私人照片应使用私人笔记附件。打赏只展示账号／二维码，不是支付系统。

## 换壁纸、配色和导航

“外观设置”提供桌面／手机壁纸、横幅文案、默认配色、导航、侧栏、阅读、字体和页脚等分组。图片可以直接上传或从素材库选择；列表使用上／下按钮排序，字体按名称和真实示例选择。

- 网站名称、作者、头像和Logo在“设置”中管理，避免两套来源。
- 保存修改的是网站默认值，不清除访客浏览器里已经选过的颜色或显示偏好。
- “恢复本组默认”只恢复这一组；“设置历史”保留最近20份非敏感设置。
- “生成登录态预览”不会切换公开站点；预览仅管理员可见，24小时有效。

## 素材替换与删除

公开素材库中的文件任何访客都能访问。图片最大20MiB、音频100MiB、歌词1MiB；分块上传中断后可以选择同一文件续传。

“重命名”只改显示名称。“替换使用处”先选择同类型新素材，然后一次更新当前文章、页面、笔记、Wiki、站点和主题设置中的引用。旧文件地址与字节不改变；设置历史、Wiki备份、待处理候选及旧公开版本继续保留它，引用释放后才允许删除。

替换与恢复共用可回滚文件事务。有正在保存或读取的操作时可能要求稍后重试，新上传文件会保留，不用再次上传。

## AI与第三方服务

“AI服务”添加具名连接：填写完整API基础地址和密钥，保存后获取模型列表并选择默认模型。地址按填写值使用，不重复添加 `/v1`。无法列出模型时可手工填ID；真实流式／工具调用测试必须由你确认费用后发起。修改配置不影响已运行任务。

“服务接入”配置评论、Memos、统计和追番平台。连接检查只检查已保存字段和列出的HTTP地址；可达不等于账号权限、数据内容或事件统计已正确。审核、收藏和报表在原服务管理。不要把私密令牌放进公开主题配置；私人工作区与预览不启用公开统计或录屏。

## 更新、备份与助手

- 日常内容和装修不需要更新镜像或主题包。
- 主题代码升级才上传[独立主题包](independent-theme.md)。后端程序或运行环境变化才换镜像。
- 数据误操作前先创建并下载[备份](backup-and-onboarding.md)，凭据需另行保管。
- [Hermes接入](hermes.md)默认只直接写草稿；公开内容与外观修改在“助手与审批”中查看差异后批准。
- 主题故障时进入“自定义后台路径/maintenance”；它不依赖主题资源，可安装／回退主题、恢复事务、处理审批和撤销助手。
