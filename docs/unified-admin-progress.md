# 统一后台实施记录

## 当前状态

功能实现已进入最终发布验收：独立后端镜像、主题包、统一后台和Hermes受控管理均已落地。最终稳定镜像仍由迁移整链门禁决定，未通过前不宣称全部交付完成。

主代理独立执行；不访问共享盘、不操作生产服务器。用户已授权提交main、推送Git和版本化镜像／主题包。AI自动测试均使用模拟服务，Hermes验证不调用模型。

## 已实现

- 保留固定Firefly源码、布局、背景、字体、响应式和原组件；内容适配、后台与私人入口集中扩展，原SPA/自定义目录合同保留。
- 统一后台按内容、装修、私人知识、服务与维护组织；手机使用紧凑分区选择。文章、页面、动态、项目、模块内容、外观、素材、AI、Wiki、引导、维护和助手均有真实API。
- 内容模块支持音乐本地列表/Meting、公告、友链、书签、打赏与公开相册；第三方审核、统计和收藏继续在原平台管理，本站提供有明确范围的配置/连通性检查。
- 素材分块续传、格式限制、尺寸与引用、重命名、当前引用事务替换、历史/候选/公开版本删除保护；歌词不接受HTML。事务复用恢复日志，不另建数据库。
- 编辑器草稿保存、摘要、常用Markdown、展示字段、slug别名与私有预览；外观历史、原版字体名称与真实示例、首次引导和示例归属清理。
- 数据备份、验证、恢复前安全备份、中断恢复、站点检查和独立维护入口；恢复配置revision前进，不覆盖凭据。
- 多AI连接、模型发现/选择、明确配置来源、任务固定连接版本、受控内网与无跨域重定向；费用测试必须明确确认。
- 独立主题包包含源码、原素材和已安装依赖；固定GitHub Release摘要校验，路径/链接边界、平台/接口兼容、可写副本与安装版分离；成功才同时切换页面/主题，回退重建当前内容。
- Hermes官方Go SDK同进程/mcp、独立摘要凭据与Host绑定、默认公开/草稿权限、私人单独授权、不可变候选、差异审批、精确版本/内容绑定、幂等、审计和撤销。旧机器key不获得新增权限；不提供Shell、删除、恢复、主题安装或批准工具。
