# 统一后台实施记录

## 目标与固定约定

已批准全部范围：Firefly 原版外观；日常内容模块；引导、素材库、私有预览、设置历史、备份恢复、健康检查；独立主题包；Hermes MCP/服务端审批；后台 AI 连接和模型选择。主代理独立顺序实施，不访问共享盘、不操作生产服务器。

原 API、Markdown 和环境配置合同保持。不增加数据库或常驻 Node 页面服务。公开变更串行构建；撤回不泄露旧内容。主题升级不覆盖个人设置。自动测试不调用收费模型。Hermes 默认只能直接操作草稿，公开变更后台批准，不自动获得私人数据或凭据权限。

## 发布约定

用户已明确允许提交 main 和构建推送镜像。按功能分批提交；main 的 CI 产出 sha-提交号候选镜像，container-v主版本.次版本.修订号发布标签才更新版本镜像及 latest。阶段检查点不是整体完成版本。

初始检查点 d053d23 已推送到 codex/unified-admin。当前批次修复浏览器与隐私验收发现的问题后，合入 main。后续继续在 main 分批提交。

## 已落地能力

- internal/configdoc：版本化 JSON、原子保存、revision 冲突。
- AI：多连接、模型发现、显式费用确认测试、默认来源、对话选模型、固定任务配置、runner 版本缓存、内网显式许可、重定向禁用、响应大小限制。密钥不回显、不进入公开快照。
- 外观与模块：白名单 schema、原版默认值导出与配置适配；壁纸、配色、导航、侧栏、音乐、公告、友链、书签、打赏、相册、字体、页脚、访客面板、动态来源及公开第三方配置。
- 素材：分块上传、续传、格式校验、列表、预览/试听、基本引用删除保护；外观表单可选择/上传素材。
- 内容：独立动态/项目 Markdown 集合；系列、评论等展示字段；旧调用保留新增元数据；草稿自动保存、摘要、插入工具、已发布链接别名、about 页面绑定。
- 恢复体验：20 份外观设置历史；登录态真实 Firefly 预览，私有页面与资源鉴权，恢复历史不回退文章。
- 隐私：私人工作区与预览禁用统计；公开/私人边界完整导航；草稿附件鉴权；私有预览资源 no-store。
