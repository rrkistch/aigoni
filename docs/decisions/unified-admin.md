# Agent Note: 后台配置与模型任务隔离

Status: implemented

## Problem

模型仅由环境配置提供，用户必须修改服务器文件；缓存 runner 会使修改模型后仍使用旧配置。

## Decision

后台模型连接使用独立、0600 权限的版本化文档，不进入公开快照。管理员必须重新提交变更地址的密钥。新连接使用检查 DNS 后直连的 HTTP 客户端，禁止重定向；内网需显式开启。原环境连接保留兼容合同。新任务捕获配置版本，缓存只复用相同版本；已有任务保留旧 runner。

## Alternatives considered

- 浏览器直连模型：泄露凭据且受跨域限制，不采用。
- 修改环境变量并重启：影响正在运行的任务，不采用。
- 自动发起测试：可能产生费用，仅显式确认后测试。

## Consequences

模型列表不代表能力认证，提供独立流式/工具调用测试。新增私密配置不纳入公开设置或未来非敏感备份。计划的其余交付进度见 ../unified-admin-progress.md。


## 素材替换复用恢复事务

素材文件始终不可变。替换先上传新文件，再以维护锁暂停引用写入，使用现有sitebackup文件事务更新当前引用及元数据；中断由同一个启动恢复日志回滚，不另建事务平台。配置版本随引用变化前进，旧公开快照、历史、Wiki备份和待处理候选保留原文件。只读扫描失败时拒绝删除。新接口的文本批量上限避免小内存服务器一次读取任意大文档。
